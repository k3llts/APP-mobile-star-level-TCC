# Star Level

**Star Level** é um projeto de Trabalho de Conclusão de Curso (TCC) desenvolvido pelos alunos da **ETEC Professor Basilides de Godoy**, em colaboração com o grupo de Desenvolvimento de Sistemas (DS).

O projeto consiste no desenvolvimento de um aplicativo mobile com temática de jogos e personagens, reunindo conteúdos informativos, elementos interativos e recursos de gamificação em uma única plataforma.

## Sobre o projeto

O Star Level foi desenvolvido com o objetivo de oferecer uma experiência interativa e divertida aos usuários, apresentando diferentes conteúdos relacionados ao universo do projeto.

A aplicação possui uma interface personalizada, com temática visual inspirada em jogos digitais, utilizando elementos gráficos, cores e fontes que reforçam sua identidade.

## Funcionalidades

O aplicativo conta com diferentes páginas e recursos:

- **Blog:** apresentação de conteúdos e artigos relacionados ao projeto.
- **Lista de personagens:** exibição de personagens, suas descrições e informações.
- **Catálogo de produtos:** apresentação de produtos fictícios, com imagens, descrições e preços.
- **Itens:** exibição de itens e objetos presentes no universo do aplicativo.
- **Controles:** apresentação dos comandos e instruções de utilização.
- **Curiosidades:** conteúdos informativos e curiosidades sobre o universo do projeto.
- **Sobre:** informações sobre o projeto e seus desenvolvedores.
- **Gamificação:** conteúdos relacionados à utilização de elementos de jogos para tornar a experiência mais interativa.
- **Newsletter:** formulário para preenchimento de informações dos usuários, como nome, e-mail e comida favorita.

## Tecnologias utilizadas

As principais tecnologias e ferramentas utilizadas no desenvolvimento foram:

- **Flutter:** framework utilizado para desenvolver a aplicação.
- **Dart:** linguagem de programação utilizada na implementação das funcionalidades.
- **Material Design 3:** sistema de design utilizado como base para os componentes visuais.
- **Git e GitHub:** ferramentas utilizadas para versionamento, armazenamento e colaboração no projeto.
- **Visual Studio Code:** editor de código utilizado durante o desenvolvimento.

## 🚀 Como executar o projeto

Para executar o aplicativo em seu ambiente de desenvolvimento, siga as etapas:

**1. Pré-requisitos**

- Flutter instalado e configurado.
- Dart SDK.
- Visual Studio Code ou outra IDE compatível.
- Emulador Android, dispositivo físico ou navegador compatível.

**2. Clone o repositório**

```bash
git clone https://github.com/k3llts/APP-mobile-star-level-TCC.git
```

**3. Acesse a pasta do projeto**

```bash
cd APP-mobile-star-level-TCC
```

**4. Instale as dependências**

```bash
flutter pub get
```

**5. Execute a aplicação**

```bash
flutter run
```
